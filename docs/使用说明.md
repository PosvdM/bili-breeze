# 哔哩清风

识别 B 站动态和视频置顶评论中的广告，按你的选择折叠内容。支持 Jev 和兼容接口，使用你自己的 API 密钥。

## 安装

从发行版下载 ZIP 安装包，无需解压。打开 Chrome 或 Edge 的扩展管理页，开启「开发者模式」，将 ZIP 直接拖入页面，按提示完成安装。更新时拖入新版 ZIP，会覆盖原扩展并保留设置、名单和记录，完成后刷新 B 站页面。

从 1.0 或 1.0.1 升级时，新版会作为另一个扩展安装，需要重新填写 API 设置和名单，再移除旧版本。1.0.2 起之后的更新不再需要这样做。

## 过滤

在「识别范围」选择动态或视频置顶评论，在「自动折叠」选择内容类别：

- 广告：商品推广、品牌宣传、带货等内容。
- 抽奖：以奖品和参与方式为主要内容的抽奖。
- 包含附带抽奖：同时折叠新闻、活动等内容附带的抽奖。需要开启「抽奖」。
- 活动宣传：见面会、展会、演出、比赛等通知和邀约。
- 招聘：员工、实习等岗位招录。

官方账号介绍自家作品的预告、实机和开发进展通常不算广告；优惠促销、周边带货和第三方合作仍按广告判断。已有自定义 Prompt 会保留，想使用新规则时请重置为内置 Prompt。

默认开启广告和抽奖。不同类别可同时命中。抽奖由关键词和模型共同判断，主次不确定时不因抽奖折叠。点击「展开内容」可查看被折叠的内容。

## 过滤强度

广告置信度达到「广告折叠阈值」时折叠，默认 70%。谨慎模式使用更高的阈值，默认 90%，用于减少误判。百分比可拖动滑条或直接输入，修改后自动保存。谨慎模式的实际阈值不会低于普通广告阈值。

开启「自动启用谨慎模式」后，按每位 UP 主最近检测的动态计算广告占比。默认积累 10 条不同动态、广告占比达到 40% 时，自动加入「谨慎过滤」名单并持续生效。统计条数可设为 2–100 条，占比和置信度可设为 1–100%。

统计按本机首次检测顺序计算，同一条内容只计一次。仅使用当前分类规则下完成识别的动态；置顶评论和跳过识别的内容不计入。记录不足时继续积累，未取得 UID 时暂不能计算。可在「记录与统计」查看积累进度和谨慎模式状态。

页面底部的「识别 Prompt」是判断广告、招聘和活动宣传的内置 Prompt，可直接修改，最多 4,000 字；点击「重置为内置 Prompt」或清空即可恢复。输出格式由扩展固定附加，抽奖主次仍用内置规则。修改后内容会重新识别，使用你的 API 额度；恢复内置 Prompt 后可复用同一规则版本的缓存；内置规则更新后会重新识别。1.0.3 中填写的补充规则会自动接在内置 Prompt 末尾。

## 名单

「始终显示」中的 UP 主不折叠，也不调用 API。「谨慎过滤」中的 UP 主始终使用谨慎模式的广告阈值，抽奖、活动和招聘仍按分类开关处理。

自动加入的 UP 主标注为「自动添加」。关闭自动启用仅停止添加新名单，已有名单继续生效。移除后不会再次自动加入，需要时可手动添加。

也可在 UP 主动态页左侧「全部」「视频」下方点击「加入白名单」或「谨慎过滤」，再次点击可移除。两个名单同时启用时，白名单优先。

输入 UP 主的数字 UID 即可添加。扩展会获取名字，方便辨认。名字获取失败时保留 UID，可点击「获取名字」重试；改名不影响 UID 匹配。置顶评论按视频 UP 主匹配。

## API

Jev 直接连接 api.typesafe.ai。自定义服务支持 OpenAI Chat Completions 或 Jev 兼容接口，请填写完整 HTTPS 接口地址、模型名称和密钥，并允许浏览器访问该域名。

密钥仅保存在本机。识别会将文字、作者名称、标题和内容链接发送给你选择的服务商，使用你的 API 额度。扩展不分析图片或视频，也不连接中转服务器。

## 缓存与记录

识别结果在本机缓存 30 天，最多 5,000 条。相同内容和服务配置可复用结果；调整阈值或分类开关无需重新请求模型。内容、模型、接口或分类规则变化时会重新识别。

「记录与统计」保存最多 5,000 条去重记录，包括作者、摘要、分类和当次处理结果。统计只代表本机检测过的内容，不代表作者全部投稿。模型可能误判。调整设置后，未重新查看的历史记录仍保留当时的处理结果。

扩展会提前检测页面已加载的附近内容。网络较慢或快速滚动时，折叠可能延迟。
