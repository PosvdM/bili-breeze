# 规则配置

识别 Prompt 和默认阈值是仓库中的数据文件，不写在代码里。扩展每天从 GitHub 读取一次，修改这些文件后无需发布新版本。

## 文件

| 路径 | 内容 |
| --- | --- |
| `config/stable/prompt.md` | 正式通道的识别 Prompt，纯文本，最多 4,000 字 |
| `config/stable/thresholds.json` | 正式通道的默认值：`adThreshold`、`cautiousThreshold`、`ratioThreshold`、`ratioWindow` |
| `config/beta/` | 内测通道，文件名与正式通道相同；缺少的文件使用正式通道的版本 |

Prompt 包含广告、招聘、活动宣传和抽奖主次的全部规则。输出格式和各问题的结尾（如“返回广告概率。”）与代码中的字段对应，由 `prompts/request.js` 附加，不放在配置文件中。

`thresholds.json` 的四个值都必须是整数：三个百分比为 1–100，`ratioWindow` 为 2–100。缺少字段或超出范围时，整个文件视为无效。

打包时 `config/stable/` 会一起放进安装包，作为内置版本。因此 `main` 分支上的正式配置既是远程来源，也是下一次发布的内置版本。

## 读取与更新

逻辑位于 `rules.js`，由后台脚本加载。

- 后台脚本启动时检查上次成功更新的时间，超过一天时重新读取。持续浏览时后台脚本可能长时间不重启，因此识别内容时也会触发同样的检查，每小时最多一次。失败后一小时内不再重试，避免主机不可达时每次启动都发请求。
- 弹窗中的「立即更新」和切换通道会立即读取；已有检查在进行时，等它结束后再读取一次。
- 读取顺序：先请求 `raw.githubusercontent.com`，超时 5 秒；连接失败、超时或返回错误时，改用 `ghfast.top` 代理同一地址。
- 内测通道先读 `config/beta/`。主机返回 404 时读 `config/stable/`。
- 每个文件单独校验、单独生效。某个文件读取失败或格式无效时，保留上次缓存的版本；没有缓存时使用内置版本。
- 切换通道后，不属于新通道的缓存不再使用。正式通道只接受正式文件，内测通道接受内测和正式文件。

`chrome.storage.local` 中的相关键：

| 键 | 内容 |
| --- | --- |
| `ruleChannel` | `stable` 或 `beta`，默认 `stable` |
| `remoteRules` | 远程文件的缓存：`{prompt: {value, host, channel}, thresholds: {...}}` |
| `ruleCheck` | 最近一次检查：`{channel, checkedAt, attemptedAt, error}` |

`ruleCheck` 每次检查都会变化，因此与 `remoteRules` 分开保存。只有 `remoteRules` 变化时，后台脚本才通知页面重新判断。

## 默认值与用户设置

阈值、统计条数和 Prompt 只在与默认值不同时保存。没有保存的项使用当前默认值，并随规则更新变化。

- 弹窗中的值等于默认值时，删除对应的键。
- 规则更新后，与新默认值相同的已保存值会被删除，之后跟随默认值。
- 弹窗用洋红色标出使用默认值的项：滑条圆点、统计条数输入框边框和 Prompt 输入框边框。

## 缓存与样本

识别结果的缓存键包含实际使用的 Prompt（用户修改版或默认版）和 `prompts/request.js` 中的 `REQUEST_VERSION`。Prompt 变化后，旧结果不再使用。修改问题措辞或输出字段时，需递增 `REQUEST_VERSION`。

记录中的 `classificationVersion` 是实际 Prompt 的 SHA-256 摘要的前 16 个十六进制字符。自动谨慎模式只统计与当前 Prompt 相同的记录。

## 修改规则

1. 在 `config/beta/` 中放入修改后的文件，只需放有改动的文件。
2. 在弹窗「过滤强度」页把通道切换为「内测」，验证识别效果；Prompt 的评估方法见 [Prompt 回归样例](prompt-evaluation.md)。
3. 确认后把文件复制到 `config/stable/`，并删除 `config/beta/` 中的对应文件。

`raw.githubusercontent.com` 的响应最多缓存 5 分钟。正式通道的用户最迟在一天后读取到新规则。

## 隐私

读取规则时，GitHub 和 `ghfast.top` 能看到请求者的 IP 地址和请求时间。请求不携带 Cookie，也不包含 API 密钥或浏览内容。`ghfast.top` 是第三方代理，可以修改返回内容；扩展只校验格式，无法确认内容来自本仓库。规则内容只影响识别结果，不会作为代码执行。
