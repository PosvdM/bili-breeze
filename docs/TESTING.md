# 测试

运行 `npm install` 后执行 `npm test`。浏览器测试需要本机安装 Chrome 和 Edge。

## 覆盖范围

- Jev 和 OpenAI 兼容接口、域名权限、消息来源检查与错误处理。
- 请求去重、并发限制、缓存过期与后台重启后的缓存读取。
- 广告、抽奖主次、活动宣传和招聘的独立判断。
- UID 名单、自动谨慎过滤的持久保存及移除行为。
- 动态、转发和置顶评论的提取、折叠、展开与路由切换。
- 接口临时不可用时的自动重新检测。
- 扩展 ID 固定，拖入新版 ZIP 时覆盖原扩展并保留数据。
- 弹窗设置、滑条与数字输入、默认值的洋红色标记与恢复按钮、规则通道切换与立即更新、名单快捷按钮及固定侧栏位置。
- 识别 Prompt 包含抽奖主次规则，修改后替换全部规则；恢复默认、长度上限和固定的输出格式。
- Jev 和 OpenAI 接口接收作者名称，作者变化后重新识别。
- 默认 Prompt 变化后旧缓存失效，旧判定不计入自动谨慎样本；保存与默认相同的 Prompt 可复用缓存。
- 规则配置：内置版本兜底，先读 `raw.githubusercontent.com` 再读 `ghfast.top`，每天检查一次，失败后一小时内不重试，各文件单独校验，内测缺少的文件使用正式版本，与新默认值相同的设置改为跟随默认值。

本次修改已通过全套自动化测试。测试使用模拟 API 响应，不消耗真实 API 额度，也不能验证模型分类准确率。官方作品、促销和第三方合作的真实模型评估见 [Prompt 回归样例](prompt-evaluation.md)。真实 B 站页面可能随布局更新而变化。
